Why games disappear

  • You buy a license, not a game.The store button says Buy, but most digital purchases are a license that the seller can limit or end.
  • Many games need the publisher's servers.Sometimes even for single-player modes. When the servers close, the game can stop launching.
  • The law has not caught up.Consumer law covers faulty goods and copyright law protects publishers. Very little covers a working game that is switched off on purpose.

What a fair rule looks like

The Stop Killing Games campaign asks for games to be left in a working state when support ends. It does not ask for support forever.

In my report I suggest a balanced model:

  1. Show the support period and server needs on the store page before purchase.
  2. Give long notice before shutdown, and a refund if a game ends earlier than promised.
  3. Prepare an end-of-life plan: an offline mode, a patch, or a release of the server software.
  4. Give small studios and true live-service games lighter duties.

Both sides have a point

  • Customers pay full price and expect a working product.
  • Games are cultural works, and losing them harms everyone.
  • Some publishers already release offline patches or server tools, so it can be done.
  • A clear label before purchase would help buyers choose.
  • Old servers cost money and engineering time.
  • Some games were built around live services and cannot easily work without them.
  • Releasing server code can expose security problems or tools for cheating.
  • Strict rules could push small studios out of the market.

My view: honest labels and a clear end-of-life plan protect players and still let publishers close services that no longer make money.
